Stack de infraestructura

Netlify
Frontend (SPA)
  • Build automático desde GitHub
  • Comando: vite build
  • Directorio publicado: frontend/dist
  • _redirects para rutas de Vue Router
  • Variable de entorno: VITE_API_URL
Railway
Backend (API REST + Socket.io)
  • Deploy automático desde GitHub
  • Start command: node app.js
  • Variables: MONGODB_URI, CORS_ORIGIN, SECRETO_SESION
  • Puerto inyectado automáticamente vía PORT
MongoDB Atlas
Base de datos
  • Cluster M0 (free tier)
  • Región: misma que Railway para minimizar latencia
  • Conexión vía MONGODB_URI en Railway
  • IP de Railway en allowlist de Atlas

Variables de entorno

Configuradas directamente en el panel de cada servicio — nunca en el repositorio.

Servicio Variable Descripción
Railway MONGODB_URI URI de conexión a MongoDB Atlas
Railway CORS_ORIGIN URL del frontend en Netlify
Railway SECRETO_SESION Clave secreta para express-session
Netlify VITE_API_URL URL base del backend en Railway (/api)
